# Dried blood spot proteomics for citrin deficiency — analysis code and processed results

Code, processed results and input tables accompanying the manuscript
*"Dried blood spot proteomics provides a protein-level readout for citrin deficiency"*.

Raw DIA mass-spectrometry files and DIA-NN outputs are deposited in jPOST / ProteomeXchange
(**PXD086615**, JPST005044). This repository contains everything downstream of DIA-NN that is needed to
reproduce the SLC25A13 analyses, the nested family-held-out evaluation of the exploratory classifier, the
sensitivity analyses, the frozen final model, and the computed figures and tables of the manuscript.

**Status of the classifier.** The multiprotein ensemble is exploratory: it was developed and internally evaluated
on 44 specimens from 35 families (7 LoF/Mis individuals from 5 families) and has not been validated in an
independent cohort. The frozen final model (`02_final_model/`) is provided for transparency and future transfer,
not as a validated diagnostic.

### Paths and how to run

All scripts use repository-relative paths. Run them from the repository root, e.g.

```bash
Rscript 04_SLC25A13_measurement/citrin_Fig2A_SLC25A13_ACTB.R
```

or set `CITRIN_REPO=/path/to/repository`. Each R script starts with a short header defining `REPO`, `DATA`
(`data/`) and `EXT`. The following environment variables control inputs that are **not distributed** in this repository:

| Variable | Default | Purpose |
|---|---|---|
| `CITRIN_DATA_DIR` | `<repo>/data` | `raw_data.xlsx`, `sample_info.csv`, `DBS-Tohoku.pg_matrix.tsv` |
| `CITRIN_EXTERNAL_DIR` | same as `CITRIN_DATA_DIR` | folder holding `family_map.csv` (specimen → family; available on request), `DBS-Tohoku.pr_matrix.tsv` (DIA-NN precursor matrix; in the jPOST deposit), `raw/<UniProt human FASTA>` (search database) and `DBS_nACTB_analysis_data_20250808.csv` |
| `CITRIN_MULTISEED_RUNS`, `CITRIN_PERMUTATION_RUNS`, `CITRIN_TABLE_S_WORKBOOK` | empty | per-run folders of the single-model runs and of the 100 permutations (regenerable with the harnesses; not distributed), and the supplementary-table workbook used to extract ages and sex (the derived `covariates_from_tables.csv` is distributed instead) |

Scripts that need `family_map.csv` (family-grouped cross-validation or family-cluster bootstrap): the nested-ensemble
harness and engine and their variants (`*_permAUC.R`, `*_subset.R`), the multi-seed harness, `make_permutation_plan.R`,
`ensemble_ci_bootstrap.R`, `make_table2.R`, `make_tableS_ablation.R`, `decompose_consensus30_oof.R`, `oof_covariate_checks.R`,
`slc25a13_detection_60.R`, `abundance_gate_two_step.R`, `make_tableS_SLC25A13_ROC.R`, `make_final30_QC.R`,
`top4_protein_evidence.R`, `citrin_classifier_figure_v1_8_final30.R`. Scripts that need the precursor matrix or the FASTA:
`citrin_SLC25A13_SLC25A12_precursor_detection_heatmap.R`, `precursor_consistency.R`, `peptide_uniqueness_check.R`,
`variant_peptide_check.R`, `detection_floor_check.R`, `precursor_feasibility_check2.R`, `make_final30_QC.R`,
`top4_protein_evidence.R`. Everything else runs from the distributed files alone.

## Reproducing the main results

1. **Nested family-held-out ensemble (Table 2; Tables S11, S12)** — `01_nested_ensemble/run_citrin_nested_ensemble_8workers.sh`
   (configuration of the reported run; the 6-worker launcher is equivalent; environment variables documented in the
   harness header; 35 outer families × 34 inner folds × 10 members, B = 30), then `analyze_ensemble_v1_1.R`,
   `ensemble_ci_bootstrap.R` (family-cluster bootstrap, 2,000 replicates, seed 20261105) and `make_table2.R`.
   Expected primary result (consensus-30, complete-inner-sensitivity threshold): AUC 0.834 (95% CI 0.602–0.971),
   sensitivity 7/7, specificity 31/37, balanced accuracy 0.919, Brier score 0.112.
2. **Frozen final model (Tables S17, S18)** — fitted by the same harness with `FIT_FINAL=true`; its specification and a
   worked scoring example are regenerated by `02_final_model/citrin_final_ensemble_reproducibility_20261104.R`
   (training-derived thresholds 0.034 and 0.210). `citrin_SLC25A13_LoFLoF_frozen_ensemble_scoring_20261104.R`,
   `single_specimen_rescoring_both_strategies.R`, `regenerate_LoFLoF_reference_files.R` and `make_tableS_LoFLoF.R` score the
   16 LoF/LoF specimens (descriptive; Table S18).
3. **Seed sensitivity (Table S10)** — `03_sensitivity/multiseed/run_citrin_multiseed_parallel_v1_3_2.sh`
   (single-model runs: seeds 2025–2034 × {panel fixed at 30, panel size selected 5–50} × {44 specimens, Run 3 only},
   with and without training-only mean-only ComBat; family-level subsampling with seeds 2025–2029; plan files in `results/`).
4. **Control subgroups (Table S13)** — `03_sensitivity/control_subsets/oof_covariate_checks.R`.
5. **Protein exclusion (Table S14)** — `03_sensitivity/ablation/citrin_top4_ablation_familyLOFO.R` (prepare / run / compare),
   then `make_tableS_ablation.R`.
6. **Permutation reference (Table S15, Fig. S3)** — `03_sensitivity/permutation/make_permutation_plan.R` (100
   family-structured permutations, seed 20261103) → `launch_perms.sh` (`run_one_perm.sh` per permutation; harness
   `citrin_nested_ensemble_familyLOFO_v1_1_permAUC.R`, identical to the primary harness except that the inner threshold
   calibration, which does not affect the scores, is skipped) → `collect_perm_auc.R` → `make_tableS15_figS3_permutation.R`.
   Expected: 5 of 100 permutations with AUC ≥ 0.834, P = 0.059.
7. **Two-stage evaluation and abundance gate (Tables S16, S29)** — `03_sensitivity/two_stage/slc25a13_detection_60.R`,
   `two_stage_60_evaluation.R`, `ci_ppv_fp_table.R`; `03_sensitivity/abundance_gate/abundance_gate_two_step.R`
   (gate and gate + reported classifier), `run_carrier_vs_LoFMis_retraining.sh` and `evaluate_gate_then_WSvsSM.py`
   (carrier-versus-LoF/Mis retraining; negative result).
8. **SLC25A13 (Fig. 2, Fig. S1, S4; Tables S9, S24–S26)** — `04_SLC25A13_measurement/citrin_Fig2A_SLC25A13_ACTB.R`,
   `citrin_SLC25A13_SLC25A12_precursor_detection_heatmap.R`, `slc25a13_fragment_xic.py` + `slc25a13_xic_figure_final.py`
   (require the raw files from PXD086615 converted to mzML), `slc25a13_normalization_sensitivity.R`,
   `make_tableS_SLC25A13_ROC.R`, `peptide_uniqueness_check.R`, `precursor_consistency.R`, `precursor_feasibility_check2.R`.
9. **Final consensus panel (Tables S19, S20, S28; Fig. S8)** — `05_signature_proteins/make_final30_tiers.py`,
   `make_final30_QC.R`, `GO/citrin_final30_GO_reanalysis.R`.
10. **RNA-seq (Tables S22, S23; Fig. S9–S11)** — `06_RNAseq/Analysis_resubmission_RNAseq_20261103.R` (requires the
    featureCounts matrix and the sample sheet; see Data availability). Gene-level outputs of the reported run
    (`ENRICHED` gene universe, design `~ batch + sex + status`) are in `06_RNAseq/results/`.
11. **Figures** — `07_figures/citrin_classifier_figure_v1_8_final30.R` (ROC and selection-frequency tables),
    `make_Fig3A_ROC.R`, `make_Fig3B_margins.R`, `make_Fig3C_heatmap_Fig3D_selection_frequency.R`, `make_Fig3_panels_sized.R`,
    `make_workflow_figure_FigS2.py`, `make_FigS7_proteome_differential_abundance.R`.

Random seeds are fixed in every script (ensemble members 2025–2034; bootstrap 20261105; permutation plan 20261103;
normalization bootstrap 20261104; MinProb imputation of the descriptive overview 2025). Stochastic imputation means exact
numerical reproduction requires the same R random-number generator; all out-of-fold predictions and per-run outputs are
provided so that every reported number can be recomputed without re-running the models.

**Verification (2026-11-10).** In this layout, all scripts that do not require model refitting, raw files or the RNA-seq count matrix were re-run
from the repository root (non-distributed inputs supplied through `CITRIN_EXTERNAL_DIR`), and their outputs are the files distributed under
`results/`: Table 2 values and confidence intervals, the protein-exclusion, control-subgroup, two-stage and abundance-gate tables, the permutation
table and figure, the normalization and SLC25A13-ROC tables, the precursor and peptide tables, the final-panel tier and measurement-evidence tables,
the GO results, the frozen-model scores of the LoF/LoF specimens (batch and single-specimen), the frozen-model specification and worked scoring
example (manual versus glmnet agreement to 2.2 × 10⁻¹⁶), the out-of-fold contribution decomposition and the Figure 3, S1, S2, S7 and S8 panels.
The numbers printed in Table 2 and Supplementary Tables S8–S29 of the manuscript were checked against these files. Not re-run here: the nested
ensemble, multi-seed, permutation, protein-exclusion and carrier-versus-LoF/Mis model runs themselves (hours to days of compute; their aggregated
outputs are distributed), the fragment-XIC extraction (needs the raw files from PXD086615) and the RNA-seq analysis (needs the count matrix).

## Data availability

* Raw DIA files, DIA-NN report and spectral library: jPOST / ProteomeXchange PXD086615 (JPST005044).
* Protein-group matrix, DIA-NN `pg_matrix` and specimen metadata: `data/` in this repository. The DIA-NN precursor matrix is part of the jPOST deposit.
* **Family structure.** The specimen-to-family map (`family_map.csv`) is not distributed and is available from the corresponding author on request; specimen-level family identifiers have been removed from all distributed tables (the per-fold tables keep the held-out fold label `held_family`, which is not linked to specimens). Because thresholds are calibrated per outer fold, specimens of one held-out family share the same fold-specific threshold in the out-of-fold prediction table. Scripts that need the family map read it from `CITRIN_EXTERNAL_DIR` (helper `add_family()` in their header).
* PBMC RNA-seq raw data and the per-specimen count matrix are not publicly available because of consent restrictions; access to de-identified processed data can be requested from the corresponding author under the conditions stated in the manuscript.
